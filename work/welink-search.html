WeLink 搜索交互改版

WeLink Search Redesign · UX / Interaction
项目角色交互设计 / 需求分析
服务对象华为 WeLink（企业协同）
所属章节01 产品构建

01 项目背景

华为 30 余年发展中，内部各业务部门独立开发了大量 APP，"APP 繁多、系统割裂"成为效率黑洞。2016 年华为启动数字化转型，由质量与流程 IT 管理部推动，WeLink 正式立项。搜索是 WeLink 作为企业协同入口最高频的能力之一——用户需要在统一入口内找到应用、联系人、知识文档与服务。

改版前，搜索能力分散在多个模块：应用入口各自为政、联系人依赖通讯录多级跳转、知识文档缺少统一检索。内部调研显示"找不到、找得慢"是高频吐槽点之一。本次改版目标，是把分散的检索收敛为一个统一、智能、可预期的搜索体验。

02 我的角色

独立负责搜索模块的需求分析与交互方案设计，输出交互稿并推动开发落地，参与改版后的数据回收与迭代。

【占位：如还有他人协作，简述分工】

03 设计流程

  • 问题定义：通过用户访谈与埋点数据，梳理出三大待解问题——入口分散、结果无分类、缺少搜索记忆。
  • 方案探索：对比"全局统一搜索框"与"各模块本地搜索"两种思路，从复用性与用户心智成本角度选择前者；结果页采用「应用 / 联系人 / 公众号 / 知识」四分类聚合。
  • 关键决策：引入模糊联想、热词推荐与搜索历史直达，并在结果不足时给出"换种说法"的引导。

04 方案展示

搜索首页：热门应用 + 常用联系人 + 历史记录三段式，降低冷启动成本；

结果聚合页：四分类 Tab + 各分类内卡片列表，支持关键词高亮；

空结果引导：提供"试试这些""联系 IT 助手"等兜底路径。
