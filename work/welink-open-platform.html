华为云 WeLink 开放平台

WeLink Open Platform · UX / UI / B 端
项目角色UX / UI（门户 + 控制台）
服务对象华为 WeLink（开发者 / ISV）
所属章节01 产品构建

01 项目背景

WeLink 除自身能力外，需要开放 API 与应用市场，让企业自建应用与第三方 ISV 接入。开放平台是面向开发者的 B 端产品：文档、控制台、应用管理，与 C 端消息 / 通讯录的设计逻辑完全不同——用户更专业、目标更明确、容错更低，对信息密度与操作确定性的要求更高。

02 我的角色

负责开放平台门户与开发者控制台的 UX / UI 设计，输出信息架构与高保真稿。

03 设计流程

  • 梳理开发者旅程：注册 → 创建应用 → 调试 → 上架 → 运营，确保每个阶段都有清晰的下一步；
  • 文档与控制台分离：二者视觉一致但职责清晰，降低跨页认知成本；
  • 就近提示：关键操作（密钥、回调、计费）提供"解释 + 示例 + 校验"的就近提示。

04 方案展示

门户首页：能力地图 + 快速开始，降低上手成本；

应用管理：列表态突出状态（审核中 / 已上架 / 异常），详情页聚合配置与数据；

接入文档页：左侧目录 + 右侧内容 + 代码块一键复制。
