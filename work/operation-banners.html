宣传运营 Banner

Operation Banners · Visual / Illustration
项目角色创意 / 插画 / 排版
服务对象WeLink 及生态应用
所属章节02 运营提升

01 项目背景

WeLink 及其生态应用的日常运营需要持续产出 Banner：应用市场推荐、功能上新、节日活动、内部宣导。要求在极小的版面内完成"品牌识别 + 卖点传达 + 行动引导"三重任务。

02 我的角色

独立负责系列 Banner 的创意、插画与排版。

03 方案展示

WeLink 应用市场："精选推荐应用，企业所有管理问题，一个 WeLink 都搞定"——蓝色系 + 2.5D 建筑插画。

泛微办公 OA："一体化移动办公平台"——紫蓝渐变 + 办公场景插画。

2018 新员工必看宝典："账户权限 / 知识经验 / 考勤制度"——书本 + 旅程插画，蓝 / 红 / 黄多色版适配不同投放位。

智慧差旅："工作少奔波，生活多自由"——机票按钮 + 场景插画。

品学堂·寻找华为最美之声：橙色听书人插画，与活动 H5 呼应。

04 成果与价值

  • 多组 Banner 被采纳为部门运营模板，复用至【占位：N 个投放位】；
  • 重点活动 Banner 点击率【占位：xx%】。
