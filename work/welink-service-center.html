华为云 WeLink 服务中心

WeLink Service Center · UX / UI
项目角色信息架构 / UX / UI
服务对象华为 WeLink（政企 / 高校客户）
所属章节01 产品构建

01 项目背景

WeLink 面向 B 端政企客户与高校客户，用户分布于制造业（14.8%）、教育 / 科研（13.6%）、IT 与互联网（10.4%）等行业；企均使用调研回收问卷 2668 份、有效 2168 份，有效回收率 86.9%。大量 IT 服务（请假、差旅、报修、审批）入口分散，员工"办事找不到入口"的摩擦长期存在。服务中心的目标，是把它们聚合为一个统一的服务门户，让办事像点外卖一样简单。

02 我的角色

负责服务中心的信息架构与核心模块（个人中心、服务助手、云服务引导）的 UX / UI 设计，并交付交互与视觉稿。

【占位：如有视觉之外的协作分工，简述】

03 设计流程

  • 梳理服务清单：盘点高频服务，按"办理类 / 查询类 / 申请类"归类，明确入口归属；
  • 设计服务助手：以对话入口承接模糊需求（如"我要请假"直接引导至办理页），降低查找门槛；
  • 分层个人中心：以"常用功能九宫格 + 我的服务"分层，减少首页信息负担。

04 方案展示

个人中心：常用功能九宫格 + 我的服务 / 关注 / 收藏分层，对应作品集其他页面；

服务助手：对话式服务入口，支持按关键词直达办理页，呼应通讯录页"小助手"能力；

云服务：首次上传引导开通 5GB 空间的转化弹窗设计，用进度感与权益说明提升开通率；

登录页：手机号 + 验证码的轻登录流程，降低首次使用摩擦。
