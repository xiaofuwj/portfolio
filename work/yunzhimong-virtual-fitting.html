云之梦在线试衣

Yunzhimong Virtual Fitting · UI / Interaction / Motion
项目角色UI 设计 / 交互 / 动效配合
服务对象云之梦科技（服装品牌 SaaS）
所属章节01 产品构建

01 项目背景

深圳云之梦科技（2016/4–2018/4 任职期间）主打 AI + 3D 虚拟试衣技术，为服装品牌提供线上试穿解决方案。电商场景中"看得到、试不了"是服装品类退货率高、客单价受限的核心原因之一。在线试衣要同时解决真实感（身材 / 尺码还原）与流畅感（试穿操作的即时反馈）两个问题。

02 我的角色

担任 UI 设计师，负责试衣主流程界面、模特 / 衣物选择交互，并与动效配合完成换装反馈设计。

03 设计流程

  • 数据录入：提供"拍照量体"与"手动填参"两种身材采集方式，降低首次使用门槛；
  • 流程精简：将选款 → 试穿 → 调尺码 → 加购 压缩为单屏内可完成的连续操作；
  • 弱网策略：3D 渲染未就绪时先展示轻量占位与骨架，避免白屏焦虑。

04 方案展示

试衣主界面：左侧模特、右侧衣物库的分栏布局，支持按品类 / 风格筛选；

换装操作：点击衣物即触发换装动效，尺码推荐结果以卡片呈现并支持一键调码；

结果页：试穿快照可保存、分享或直达购买。
