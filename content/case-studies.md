### 1. WeLink 搜索交互改版

**Slug**：`welink-search`　**标签**：UX / 交互设计　**一句话简介**：让 30 万企业员工的"找应用、找人、找知识"一步直达。

**项目背景**
华为 30 余年发展中，内部各业务部门独立开发了大量 APP，"APP 繁多、系统割裂"成为效率黑洞。2016 年华为启动数字化转型，由质量与流程 IT 管理部总裁陶景文团队推动，WeLink 正式立项。搜索是 WeLink 作为企业协同入口最高频的能力之一——用户需要在统一入口内找到应用、联系人、知识文档与服务。

改版前，搜索能力分散在多个模块：应用入口各自为政、联系人依赖通讯录多级跳转、知识文档缺少统一检索，用户平均需要【占位：N 次点击 / N 步】才能找到目标，内部调研显示"找不到、找得慢"是高频吐槽点之一。本次改版目标，是把分散的检索收敛为一个统一、智能、可预期的搜索体验。

**我的角色**
独立负责搜索模块的需求分析与交互方案设计，输出交互稿并推动开发落地，参与改版后的数据回收与迭代。 【占位：如还有他人协作，简述分工】

**设计流程**
- **问题定义**：通过用户访谈与埋点数据，梳理出三大待解问题——入口分散、结果无分类、缺少搜索记忆。
- **方案探索**：对比"全局统一搜索框"与"各模块本地搜索"两种思路，从复用性与用户心智成本角度选择前者；结果页采用「应用 / 联系人 / 公众号 / 知识」四分类聚合。
- **关键决策**：引入模糊联想、热词推荐与搜索历史直达，并在结果不足时给出"换种说法"的引导。

**方案展示**
- 搜索首页：热门应用 + 常用联系人 + 历史记录三段式，降低冷启动成本；
- 结果聚合页：四分类 Tab + 各分类内卡片列表，支持关键词高亮；
- 空结果引导：提供"试试这些""联系 IT 助手"等兜底路径。
【占位：补图——搜索首页、结果聚合页、空状态三张截图】

**成果与价值**
- 搜索点击率提升【占位：xx%】；
- 人均查找步骤由【占位：N 步】降至【占位：M 步】；
- 上线覆盖【占位：企业数 / 用户数】。
【占位：如有权威数据来源（如内部复盘报告），在此注明出处】

### 3. 云之梦在线试衣

**Slug**：`yunzhimong-virtual-fitting`　**标签**：UI / 交互 / 动效　**一句话简介**：用 3D 虚拟试衣，把"尺码合不合适"的犹豫变成下单的决心。

**项目背景**
深圳云之梦科技（2016/4–2018/4 任职期间）主打 AI + 3D 虚拟试衣技术，为服装品牌提供线上试穿解决方案。电商场景中"看得到、试不了"是服装品类退货率高、客单价受限的核心原因之一。在线试衣要同时解决**真实感**（身材 / 尺码还原）与**流畅感**（试穿操作的即时反馈）两个问题。

**我的角色**
担任 UI 设计师，负责试衣主流程界面、模特 / 衣物选择交互，并与动效配合完成换装反馈设计。

**设计流程**

- **流程精简**：将选款 → 试穿 → 调尺码 → 加购 的流程压缩为单屏内可完成的连续操作；

**方案展示**

- 换装操作：点击衣物即触发换装动效，尺码推荐结果以卡片呈现并支持一键调码；
- 结果页：试穿快照可保存、分享或直达购买。

### 8. 智能试衣镜动效

**Slug**：`smart-mirror-motion`　**标签**：动效 / 硬件结合　**一句话简介**：让一面镜子"活"过来——线下试衣镜的动效语言设计。

**项目背景**
云之梦智能试衣镜是线下门店硬件：用户站在镜前即可虚拟换装。屏幕动效承担三重职责：**引导**（无人指导时告诉用户怎么用）、**反馈**（换装加载、体感识别）、**氛围**（idle 状态吸引路过顾客）。

**我的角色**
负责试衣镜全部界面动效的设计与动效标注（AE 输出，配合开发实现）。

**动效设计**
- **状态机**：`idle（待机吸引）→ recognizing（体感识别）→ trying（试衣换装）→ share（保存 / 分享）` 四态流转；
- **idle 态**：柔和呼吸光带 + 缓慢漂浮的产品卖点，3-5s 循环，吸引驻足；
- **过渡**：状态切换采用 400-500ms 的位移 + 淡入，缓动统一 easeOutQuint；
- **加载反馈**：换装渲染期间用衣物"展开"动效掩盖等待，而非转圈进度。

**成果与价值**
- 落地门店【占位：N 家】；
- 单镜日均使用人次【占位：N】。

**素材对照**：简历文件夹「视频作品」「动效作品」；作品集动效章节对应页（【占位：确认页码】）。
